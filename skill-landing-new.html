有 Figma 设计稿

设计驱动路径

粘贴 Figma 链接，Skill 自动拉取设计数据，判断 3 种场景，逐步消除设计疑点，生成含设计规格的完整 PRD。

  • ①粘贴 Figma 链接，MCP 自动拉取顶层结构

  • ⑤输出设计分析包 → PRD + Acceptance Criteria

// PRD-001 · Feature 1: 灵感看板
// AC-1: 用户可拖拽截图上传
// AC-2: 自动提取颜色生成色板

import React, { useCallback } from 'react'
import { UploadZone, BoardGrid, ColorPalette }
  from './components'
import { useBoardStore } from '@/stores/board'

export default function InspirationBoard() {
  const { items, addItem } = useBoardStore()

  const handleDrop = useCallback(
    (files: File[]) => {
      files.forEach(f => addItem({ file: f }))
    }, [addItem]
  )

  return (
    <div className="board-page">
      <UploadZone onDrop={handleDrop} />
      <BoardGrid items={items} />
      <ColorPalette items={items} />
    </div>
  )
}
部署上线

说"帮我部署"，就能上线

可以在项目任意阶段触发，不必等开发完成。1 个问题判断项目类型，然后精确引导每一步操作。

你的项目有后端服务吗（需要登录账号、保存数据到数据库、有 API 接口）？

A) 没有，就是一个页面/工具（纯前端）→ 推荐 Vercel   |   B) 有，需要后端 → 推荐 Railway

纯前端 / 推荐首选

Vercel

免费 · 无需信用卡

React / Next.js / Vite 最佳搭档。自动检测框架，自动 HTTPS，全球 CDN。每次 git push 自动重新部署。

  • ①确认代码已推送到 GitHub
  • ②打开 vercel.com → 用 GitHub 登录
  • ③Import 你的仓库 → 自动检测框架
  • ④点 Deploy → 等待约 1-3 分钟
  • ⑤访问 your-project.vercel.app ✓

上线时间约 5 分钟

有后端 / 全栈项目

Railway

$5/月免费额度

Node.js / Python / 数据库一站式部署。环境变量管理友好，支持 PostgreSQL / MySQL 一键添加。

  • ①确认代码已推送到 GitHub
  • ②打开 railway.app → 用 GitHub 登录
  • ③New Project → Deploy from GitHub Repo
  • ④在 Variables 里配置环境变量
  • ⑤Settings → Generate Domain ✓

含数据库约 10 分钟
